# ЖИ субтитр студиясы

Flask-сайт: видеодан субтитр (faster-whisper), ЖИ чаты және суретті сипаттау (Groq), жеке дизайн баптаулары. Интерфейс WCAG 2.2 A/AA талаптарына бағытталған.

## Іске қосу
```
pip install -r requirements.txt
copy .env.example .env   # GROQ_API_KEY жазыңыз (міндетті емес, тек чат үшін)
python app.py
```
